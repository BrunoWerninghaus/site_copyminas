# Copy Minas Site 3 — Autoridade de conteúdo público

## Regra

Cada informação pública deve ter uma página principal responsável por ela.

Quando outra página precisar mencionar um assunto que já possui autoridade própria, ela deve preferir uma referência curta e um link em vez de repetir o conteúdo completo.

Exceções são permitidas somente quando a repetição for necessária para contexto imediato, acessibilidade ou tomada de decisão do visitante.

## Home

Autoridade:
- apresentação editorial configurável;
- avisos;
- novidades;
- produtos em destaque;
- atalhos para as demais áreas;
- visualização geográfica por globo.

Não deve repetir:
- CNPJ, razão social, data de início ou situação cadastral;
- descrições completas das soluções;
- endereço postal completo;
- ficha técnica de produtos.

## Soluções

Autoridade:
- áreas de atuação;
- escopo geral de atendimento;
- modalidades gerais de venda, aluguel e manutenção.

Outras páginas devem apontar para `/solucoes` quando o visitante precisar desses detalhes.

## Produtos

Autoridade de `/produtos`:
- catálogo;
- categorias;
- busca e filtros;
- resumo de produtos.

Autoridade de `/produtos/<slug>`:
- descrição completa do produto;
- imagens;
- modalidades específicas;
- especificações técnicas.

A Home pode exibir produtos escolhidos como destaque, pois essa repetição é editorial e navegacional.

## Empresa

Autoridade:
- nome fantasia;
- razão social;
- CNPJ;
- início das atividades;
- situação cadastral;
- sede em nível de cidade/estado.

A página não deve reproduzir catálogo de soluções, endereço postal completo ou canais de contato.

Para esses assuntos, deve encaminhar o visitante às páginas correspondentes.

## Contato

Autoridade:
- telefones e WhatsApp;
- e-mail;
- endereço postal completo;
- acesso ao Google Maps;
- formulário de solicitação;
- horário informado.

CNPJ e demais dados cadastrais pertencem à página Empresa.

## Header e footer

Autoridade:
- identidade visual;
- navegação.

Não devem funcionar como uma segunda ficha de empresa, catálogo, endereço ou diretório de contato.

## Política de manutenção

Antes de adicionar uma informação a uma página pública:

1. identificar qual página é dona daquela informação;
2. verificar se ela já está publicada lá;
3. se outra página precisar apenas conduzir o usuário, usar resumo curto + link;
4. só duplicar quando a informação for necessária naquele contexto específico;
5. evitar manter duas cópias independentes do mesmo dado em templates diferentes.
